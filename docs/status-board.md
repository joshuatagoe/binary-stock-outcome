# Status board

Notion is the only status board: https://app.notion.com/p/1515ad75bf5d4410bedf2eec1c742779

Properties: Name, Status (`Backlog`, `In Progress`, `Blocked`, `Done`), Owner, Branch, Owned files, Acceptance criteria, Test command, Evidence.

Every deliverable the spec requires has a card. Design stays in the repo docs. A card is Done only after a check that ran, with three-part evidence: the command and its result (including the failure seen first), the judgment calls made without the user, and what the diff review found.
